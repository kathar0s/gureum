# GureumChordLab 맥북 설치 안내

이 묶음은 기존 구름과 함께 설치할 수 있는 macOS용 **Local Debug/ad-hoc 실험 빌드**입니다.
실제 빌드 버전·소스 커밋·CPU 아키텍처·최소 macOS 버전은 `build-info.json`에서 확인하세요.
앱과 등록 도구가 들어 있어 대상 맥북에 Xcode나 Homebrew를 설치할 필요가 없습니다.

## 현재 동작

세벌식 배열과 libhangul의 자동 순서 교정은 기존 구름의 동작을 유지합니다.
새 Lab 설치에서는 `HangulAutoReorder` 설정이 아직 저장되지 않았을 때만 자동 순서 교정을 켭니다.
기존에 저장한 켜짐·꺼짐은 그대로 유지하며 Lab을 제거해도 이 선택은 삭제하지 않습니다.
자동 순서 교정은 자모의 순서가 바뀐 순차 입력을 libhangul에서 결합하는 기능입니다.
별도의 물리적 모아치기 엔진은 아직 구현되지 않았습니다. Debug Lab은 키 누름·해제 메타데이터를
기록해 앱별 키 해제 전달을 확인하는 단계입니다. 문자·조합 문자열·문서 내용은 기록하지 않지만,
키 코드로 입력을 추정할 수 있으므로 민감한 문구를 입력하는 일상용 입력기로 사용하지 마세요.

## 설치

1. ZIP과 함께 제공된 `.sha256` 값을 확인한 후 ZIP을 맥북의 다운로드 폴더 등에서 압축 해제합니다.
2. 현재 입력기를 ABC 또는 macOS 기본 한글로 바꿉니다.
3. 압축 해제한 폴더의 `install.command`를 실행합니다. 파일 보안 경고로 실행되지 않으면 아래 보안 설명을 먼저 확인합니다.
4. 시스템 설정 → 키보드 → 텍스트 입력 → 편집 → 추가에서 `Lab · 세벌식 최종`, `Lab · 세벌식 390` 등 원하는 배열을 추가합니다.
5. 목록에 없거나 추가·선택이 되지 않으면 로그아웃 후 다시 로그인합니다. 입력기는 앱을 직접 더블클릭해서 실행하지 않습니다.

설치 위치는 이 사용자 계정의 `~/Library/Input Methods/GureumChordLab.app`뿐입니다.
기존 Lab이 있으면 `~/Library/Application Support/GureumChordLab/Backups/lab.*/`에 보관합니다.
기존 `Gureum.app`, 다른 입력기, 다른 설정과 프로세스는 변경하지 않습니다. 관리자 암호도 요구하지 않습니다.
설치 스크립트는 앱 서명과 `SHA256SUMS`를 먼저 검사합니다.

Finder에서 명령 파일을 실행하기 어려우면 해당 폴더의 파일을 직접 확인한 뒤 터미널에서 다음처럼 실행할 수 있습니다.
이는 셸 스크립트를 실행하는 방법이며, 앱에 대한 Gatekeeper 허용이나 공증을 대신하지 않습니다.

```sh
/bin/bash "/압축을 푼 폴더/install.command"
```

## Gatekeeper와 격리 속성

이 빌드에는 Developer ID 서명과 Apple 공증이 없습니다. ad-hoc 서명은 파일 무결성 검사 용도이며
개발자의 신원을 인증하지 않습니다. 배포 파일을 인터넷·AirDrop 등으로 옮기면 macOS가
`com.apple.quarantine` 격리 속성을 추가하거나 보존해 명령 파일 또는 입력기 앱을 차단할 수 있습니다.
압축 해제·설치 도구는 격리 속성을 제거하지 않고 보존하며, Gatekeeper를 끄거나 보안 정책을 변경하지 않습니다.

차단 경고가 나타나면 시스템 설정 → 개인정보 보호 및 보안에서 해당 파일에 대한 허용 항목이 제공되는지
확인하세요. 출처와 체크섬을 신뢰할 때에만 **그 파일에 한해** 허용합니다. OS 버전이나 관리 정책에 따라
허용 항목이 없을 수 있습니다. 이때는 보안을 전체 해제하지 말고 정상 서명·공증된 배포본이 필요합니다.
Apple 안내: https://support.apple.com/ko-kr/102445

## 제거와 복구

먼저 현재 입력기를 ABC 또는 macOS 기본 한글로 바꾸고 `uninstall.command`를 실행합니다.
이 명령은 설치된 Lab만 위 Backups 폴더로 옮깁니다. 다른 입력기나 사용자 설정은 삭제하지 않습니다.
입력 소스 목록의 Lab 항목은 시스템 설정에서 제거할 수 있으며 필요하면 재로그인합니다.
복구하려면 이 묶음의 설치 명령을 다시 실행하거나 보관된 Lab 앱을 사용자 입력기 폴더로 복사합니다.

## 맥북에서 키 해제 전달 확인

Lab 자판을 선택한 뒤 `capture-events.command`를 실행하면 60초 동안 메타데이터를 수집합니다.
TextEdit 등에서 민감하지 않은 짧은 시험 문구를 실제 키로 입력하고 키를 떼세요.
터미널에 표시된 `/tmp/gureum-chord-lab-capture.*/events.ndjson` 파일에서 키 누름과 해제 쌍을 확인합니다.
Terminal, 브라우저 입력란, VS Code 터미널도 각각 별도로 시험할 수 있습니다.
키 해제가 기록되지 않으면 아직 물리적 모아치기 구현 조건을 충족했다고 볼 수 없습니다.

문제를 보고할 때는 맥북 모델·macOS 버전·배열·앱 이름과 `누른 키 → 기대 결과 → 실제 결과`를 알려주세요.
이 빌드의 설치·등록 성공은 실제 맥북에서의 모아치기 동작 검증을 의미하지 않습니다.

## 소스와 라이선스

소스는 https://github.com/kathar0s/gureum 에 있으며 이 묶음의 정확한 커밋은 `build-info.json`에 있습니다.
`libhangul-objc` 소스와 변경된 빌드 설정은 https://github.com/kathar0s/libhangul-objc 에서 확인할 수 있습니다.
이 ZIP의 `Sources/`에는 앱의 Hangul.framework를 빌드한 정확한 `libhangul-objc` 및 내부 `libhangul`의
전체 추적 소스·빌드 파일·라이선스가 각각 압축되어 있습니다. 인터넷에 접속하지 않고도 소스를 복원할 수 있으며,
정확한 커밋과 트리는 `Sources/source-provenance.json`, 복원·빌드 방법은 `Sources/README.ko.md`에 있습니다.
두 소스 압축 파일도 `SHA256SUMS` 무결성 검사에 포함됩니다.
원저작권·BSD·LGPL·자산·의존성 라이선스 고지는 `LICENSES/`에 보존했습니다.
기존 아이콘에는 별도 CC-BY-NC-ND 3.0 조건이 있으므로 이 개인 시험용 묶음을 새로운 상업용 배포본으로
간주하지 마세요. 별도 제품을 공개 배포할 때는 자산과 라이선스를 다시 검토해야 합니다.
