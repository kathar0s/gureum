바람획 ㅂ · 크기와 실루엣 비교

워드마크를 가리고 16 / 32 / 128 px 단색을 나란히 비교한다.
관찰 기준: 비읍 골격 → 평행 입구 → 아래 속공간 → 오른쪽 꼬리. 사용자 인지 실험 결과를 뜻하지 않는다.

실제 크기추천 마스터작은 크기 보정일반 바람일반 구름일반 ㅂ
16 px
32 px
128 px

16–32 px: 작은 크기 보정 원본을 사용한다. 입구를 줄이고 획을 12로 키워 내부 공간을 확보했다.
128 px 이상: 마스터 획 10, 곡선 꼬리, 큰 앱 아이콘에서 두 가닥의 색을 분리한다.
