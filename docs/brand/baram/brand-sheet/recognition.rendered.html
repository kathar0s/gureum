바람 궤적 B · 크기와 실루엣 비교

워드마크를 가리고 16 / 18 / 32 / 128 px 단색을 나란히 비교한다.
관찰 기준: 바람 우선 인식 → B의 보조 인상 → 획 간 분리 → 말림 뭉침 여부. 사용자 인지 실험 결과를 뜻하지 않는다.

실제 크기추천 마스터작은 크기 보정₿ 오인 기준일반 B일반 ㅂ

18 px
32 px
128 px

16–32 px: 작은 크기 전용 원본을 사용한다. 획을 11로 키우고 세 흐름 사이의 내부 공간을 남긴다.
128 px 이상: 마스터 획 9와 세 개의 열린 바람 말림을 드러낸다. 기본 앱 아이콘은 단색 획이다.
